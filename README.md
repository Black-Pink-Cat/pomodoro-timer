# 简易番茄钟

一个基于 Python tkinter 的桌面番茄工作法计时器。

## 功能

- **25 分钟工作计时** — 专注工作倒计时
- **5 分钟短休息** — 每个番茄结束后自动提示休息
- **15 分钟长休息** — 每完成 4 个番茄后触发长休息
- **番茄计数** — 记录当前会话完成的番茄数
- **声音提醒** — 计时结束播放系统提示音
- **窗口置顶** — 始终在最前，不被打断

## 运行

```bash
python pomodoro.py
```

仅依赖 Python 标准库（tkinter + winsound），无需额外安装。

## 使用

| 按钮 | 作用 |
|------|------|
| 开始 | 开始倒计时 |
| 暂停 | 暂停当前计时 |
| 重置 | 重置为当前阶段的初始时长 |
